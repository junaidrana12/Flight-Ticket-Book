# Flight-Ticket-Book
This project automates the end-to-end testing of a flight ticket booking system using Selenium WebDriver and TestNG. It validates key functionalities such as flight search, selection, and booking confirmation.

FlightTicketBooks is a Selenium Automation Testing project built using Java, TestNG, Maven, and Selenium WebDriver.
This project automates flight ticket search functionality on MakeMyTrip.

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- IntelliJ IDEA
- WebDriverManager
